# Code Quest – Python Learning Portal

A beginner-friendly Python reviewer built with **Python** and **Tkinter**. The application helps students study basic programming topics, review lessons, track completed topics, and answer a short quiz.

## Features

- **Registration and Login** – create an account with a username and password.
- **Dashboard** – view learning progress and navigate to the main sections.
- **Explore Lessons** – study 11 Python and computing topics with explanations and examples.
- **My Learning Progress** – see which lessons have been opened/completed.
- **Discuss All Topics** – review all lessons in sequence using Previous and Next.
- **15-Question Quiz** – answer topic-based multiple-choice questions and view your score and feedback.
- **Logout** – return to the login screen.

## Lessons included

1. Introduction to Computing
2. Python Basic Syntax
3. Printing Output
4. Python Comments
5. Variables, Constants and Database
6. Basic Data Types in Python
7. Arithmetic Operators and Expression
8. Basic Input and Output
9. Conditional Statements
10. Logical Operators
11. Iterations and Loops

## Requirements

- Python 3
- Tkinter (included with most standard Python installations)

## How to run

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python main.py
   ```

On some systems, use `python3 main.py`.

## Notes

This is a beginner/student project. Account details and lesson progress are stored in memory while the application is running. They reset when the program is closed. This demo login is not intended for real account security.
